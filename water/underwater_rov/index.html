水下无人机（ROV）MuJoCo 的建图导航 + 神经网络感知规划控制

原项目结构：model.py（MJCF 生成）→ sim.py（仿真内核 + 动力学）→ sensors.py（传感器）→ mapping.py（SLAM 占据栅格 / 扫描匹配）→ planning.py（A*+ 纯跟踪）→ nn.py（纯 numpy MLP/CNN、Adam）→ neural.py（策略封装）→ nav.py（导航主栈）+ ROS 节点 + 训练 / 评测脚本 水下版本命名：underwater_nn_nav，水下载体：ROV 水下机器人（带推进器，6 自由度，浮力 / 阻力 / 附加质量）

运行环境

  • Ubuntu 20.04

  • ROS Noetic

  • Python 3.8

class RovSim: def init(self, scene="reef_corridor", seed=0, render=False): self.layout = M.make_layout(scene,seed) self.model = mujoco.MjModel.from_xml_string(M.build_xml(self.layout)) self.data = mujoco.MjData(self.model) self.model.opt.timestep = 0.002 self.body_id = mujoco.mj_name2id(self.model, mujoco.mjtObj.mjOBJ_BODY, "rov") self.sonar_site = mujoco.mj_name2id(self.model, mujoco.mjtObj.mjOBJ_SITE, "sonar") self.ctrl = HydroController(mass=M.MASS, buoyancy=M.BUOYANCY) self.cmd = {"vx":0.0,"vy":0.0,"vz":0.0,"yaw_rate":0.0,"depth_ref":1.5} self.renderer = None self._want_render = render self.reset()

def reset(self):
    mujoco.mj_resetData(self.model, self.data)
    sx,sy,syaw = self.layout.start
    self.data.qpos[0:3] = [sx,sy,M.DEFAULT_DEPTH]
    self.data.qpos[3:7] = [math.cos(syaw/2),0,0,math.sin(syaw/2)]
    mujoco.mj_forward(self.model, self.data)
    self.ctrl.reset()
    # 稳定悬停
    for _ in range(300):
        self._physics_step()

def set_command(self, vx=0.0, vy=0.0, vz=0.0, yaw_rate=0.0, depth_ref=None):
    self.cmd["vx"] = np.clip(vx,-1.2,1.2)
    self.cmd["vy"] = np.clip(vy,-1.2,1.2)
    self.cmd["vz"] = np.clip(vz,-0.6,0.6)
    self.cmd["yaw_rate"] = np.clip(yaw_rate,-1.0,1.0)
    if depth_ref is not None:
        self.cmd["depth_ref"] = np.clip(depth_ref,0.4,3.5)

def _physics_step(self):
    pos = self.data.qpos[0:3]
    quat = self.data.qpos[3:7]
    vel = self.data.qvel[0:3]
    omega = self.data.qvel[3:6]
    # 水动力控制器输出合力、合力矩
    force, torque = self.ctrl.compute(pos, quat, vel, omega,
        self.cmd["vx"],self.cmd["vy"],self.cmd["vz"],self.cmd["yaw_rate"],self.cmd["depth_ref"])
    self.data.xfrc_applied[self.body_id,0:3] = force
    self.data.xfrc_applied[self.body_id,3:6] = torque
    mujoco.mj_step(self.model, self.data)
  1. sensors.py：声呐（替换激光雷达） 原Lidar改成Sonar，射线逻辑几乎一样，只是水下声呐有衰减噪声、最大测距，不再是激光。DVL 输出机体速度（替代原来的里程计），压力计测深度。 python class Sonar: """2D成像声呐，水平面扫描，替代激光雷达""" def init(self, model, n_beams=180, max_range=7.0, site="sonar", noise=0.04): self.model = model self.site_id = mujoco.mj_name2id(model, mujoco.mjtObj.mjOBJ_SITE, site) self.n = n_beams self.max_range = max_range self.noise = noise self.angles = np.linspace(-math.pi, math.pi, self.n, endpoint=False) self.geomgroup = np.array([1,1,1,0,0,0], dtype=np.uint8) def scan(self, data, rng=None): # 和Lidar几乎完全一致，噪声更大 p = data.site_xpos[self.site_id] r = data.site_xmat[self.site_id].reshape(3,3) fwd = r @ np.array([1,0,0]) yaw = math.atan2(fwd[1],fwd[0]) out = np.empty(self.n) for i,a in enumerate(self.angles): ang = yaw + a vec = np.array([math.cos(ang), math.sin(ang), 0.0]) d = mujoco.mj_ray(self.model, data, p, vec, self.geomgroup, 1, -1, np.zeros(1,dtype=np.int32)) out[i] = d if d>=0 else self.max_range if self.noise>0 and rng is not None: out += rng.normal(0,self.noise,size=self.n) return np.clip(out,0.05,self.max_range)
  2. mapping.py 直接复用 扫描匹配、OccupancyGrid、Slam类几乎不用改！ 输入从Lidar.ranges换成Sonar.ranges 只需要在Slam.update()里传入声呐角度，栅格更新逻辑不变，2D 平面 SLAM 完全通用。
  3. planning.py 完全复用 A*、CostMap 膨胀、PurePursuit 纯跟踪，不需要改动；导航目标是平面 xy，深度单独控制。
  4. neural.py & nn.py 几乎复用 四个网络，只改输入输出： 声呐去噪网络：输入滑窗声呐读数，输出干净声呐距离（替代激光去噪） 局部规划网络：局部占据栅格 patch + 目标相对坐标，输出前进方向 控制器网络：距离、航向误差、声呐分扇区净空、上一时刻速度，输出 (v x ​ ,v y ​ ,v z ​ ,ω z ​ ) 端到端 CNN：输入声呐灰度图（声呐扇区图像），输出机体系速度指令
  5. nav.py 导航栈 改动点： 增加深度闭环控制，维持目标深度 控制输出多了 vz（垂直速度） 碰撞检测：礁石、海底、边界墙 模式：teleop /classical（SLAM+A*） /neural 规划 /e2e 声呐端到端

evaluate.py： 评测指标：成功率、航行时间、航程、ATE（SLAM 位姿 RMSE）、碰撞次数、深度保持误差

ROS 节点、launch、main.py sim_node.py：发布/sonar（替代/scan）、/dvl、/rov/depth、IMU、真值位姿 nav_node.py：订阅声呐，跑 SLAM+A*，发布/cmd_vel（twist，linear.z 是垂直速度） teleop_node.py：按键增加上升 / 下降 main.py无 ros 入口，mode 参数：teleop / nav / neural / e2e / test / demo
